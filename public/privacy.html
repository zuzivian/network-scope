How privacy works

Your network never leaves your device. There is no server that receives it, no account, no analytics and no cookies.

What happens when you add a file

  • The file is read by code running in this page, in your browser. It is not uploaded anywhere.
  • Contact details are dropped as the file is read, before anything is saved: see the table below.
  • What's left is saved in your browser's own storage for this site (IndexedDB). Other sites can't read it, and neither can we.

The only things this page sends over the internet

  • Fonts from Google Fonts, when the page loads.
  • Feedback, only when you press Send in the feedback form, and only what you typed there. It goes to the maintainer through Formspree. Your map is never included.

The page enforces this itself: it ships a Content-Security-Policy whose connect-src allows only the feedback form's address. Your browser refuses any other request the page might try to make, so even a bug can't send your data elsewhere.

Check it yourself

  • Open your browser's developer tools, go to the Network tab, and add a file. You'll see no request carrying it.
  • In the same tools, look at the page's response headers for content-security-policy.
  • All the code is public: github.com/zuzivian/network-scope. The importers live in src/importers/, with tests that check each one drops contact details.

Keeping and deleting your map

  • Your map stays in this browser on this device. Some browsers can clear site data (Safari after 7 days without a visit, any browser when storage runs low), so download a backup now and then from Data → Storage. On iPhone or iPad, Add to Home Screen keeps it from being cleared.
  • A backup is a file on your computer. Restore it in any browser to carry on there.
  • Data → Storage → Delete everything in this browser removes it all, immediately.
